# EXAONE Desktop · EXAONE Code

LG AI연구원 EXAONE API(K-EXAONE 2.5, EXAONE Tabular)를 시험해 보기 위한 도구 두 가지입니다.

- **EXAONE Desktop** — Electron 데스크톱 앱. EXAONE 공식 Showroom의 워드마크와 흰색·차콜·라벤더 색상을 적용했습니다.
- **EXAONE Code** — 터미널에서 쓰는 에이전트(`exaone` 명령). 같은 API 클라이언트와 도구를 쓰며, EXAONE Code 이름과 라벤더 포인트를 사용합니다.

## 실행

Node.js 22.12 이상이 필요합니다.

| | 방법 |
|---|---|
| 데스크톱 앱 | `start.bat` 더블클릭 (또는 `npm install` 후 `npm start`) |
| 터미널 에이전트 | `install-cli.bat` 을 한 번 실행한 뒤, 새 터미널의 작업할 폴더에서 `exaone` |

데스크톱 앱은 첫 실행 때 Electron 런타임(약 100MB)을 내려받습니다. 터미널 에이전트는 `npm install` 없이도 동작합니다.

## 토큰 (API 키) 등록

**등록한 토큰만 씁니다.** 데스크톱 앱이나 터미널 어느 쪽에서든 한 번 등록하면 둘이 함께 씁니다.

- 데스크톱 앱: 토큰이 없으면 시작할 때 "EXAONE 토큰 등록" 창이 뜹니다. 나중에는 설정 → 연결에서 바꾸거나 지웁니다.
- 터미널(EXAONE Code): 토큰이 없으면 시작할 때 "데스크톱 앱에서 등록 / 여기서 바로 입력" 을 고르게 합니다. 앱에서 등록을 고르면 앱의 등록 창을 띄우고, 등록될 때까지 기다렸다가 이어 갑니다. `/login` 으로 바꾸고 `/logout` 으로 지웁니다.
- 저장 위치는 사용자 폴더의 `~/.exaone/key.txt` (Windows: `%USERPROFILE%\.exaone\key.txt`) 한 곳이며, 암호화하지 않은 텍스트 파일입니다. 화면 쪽 코드나 로그 파일에는 들어가지 않습니다.
- 폴더에 둔 `key.txt` 나 환경 변수 `EXAONE_API_KEY` 는 **더 이상 읽지 않습니다.** (예전에 앱 설정에 저장해 둔 키가 있으면 처음 실행할 때 위 위치로 한 번 옮깁니다.)

## EXAONE Desktop

### 화면 구성

- **왼쪽 위 탭: 채팅 / Code.**
  - **채팅** 탭에는 일반 대화와 에이전트 작업이 한 목록에 있습니다. 새 대화의 입력창에 있는 `채팅 | 에이전트` 버튼으로 방식을 고르고, 첫 메시지를 보내면 그 대화에 고정됩니다.
  - **Code** 탭은 터미널의 EXAONE Code 와 **같은 세션 파일**을 씁니다. 터미널에서 한 세션이 그대로 보이고, 앱에서 이어 쓴 내용은 `exaone --resume` 으로 터미널에서 이어집니다(복사본을 만들지 않습니다). 그 폴더의 `EXAONE.md` 메모리와 파일 버전 기록(`/diff` · `/rewind` ↔ 변경 사항 패널)도 함께 씁니다. 상단의 버튼이나 목록의 버튼으로 그 세션을 터미널에서 열 수 있습니다. 한쪽에서 쓴 내용은 다른 쪽에 **바로** 나타납니다: 앱은 세션 파일이 바뀌는 즉시(창을 전환하지 않아도) 목록과 열어 둔 세션을 갱신하고, 터미널은 앱이 이어 쓴 지시와 답을 `데스크톱 앱에서 이어 쓴 내용` 으로 이어서 보여 줍니다. 단계가 끝날 때마다 반영되며(글자 단위 실시간 표시는 아닙니다), 같은 세션에서 앱과 터미널이 **동시에 작업을 실행**하지는 마세요(나중에 저장한 쪽이 남습니다).
- **대화를 끌어서 프로젝트에 넣기**: 채팅 탭 목록의 대화를 프로젝트 줄(또는 그 안의 대화) 위에 놓으면 그 프로젝트로 들어가고, 아래쪽 일반 목록에 놓으면 프로젝트에서 빠집니다.
- **입력창**: `+`(파일 첨부, 작업 폴더, 시스템 프롬프트, 새 프로젝트) · 도구 버튼(출력 형식, 함수 호출 테스트) · 에이전트 모드의 승인 방식 · 오른쪽에 모델과 추론 강도.
- **오른쪽 패널** (`Ctrl+.`): 진행 · 파일 · 변경 사항 · 미리보기. 에이전트가 작업 계획을 세우면 **진행 탭이 자동으로 열려** 단계별 진행 상황과 만든·고친 파일을 보여 줍니다. 다른 탭을 볼 때도 맨 위에 진행 한 줄이 남습니다 (설정 → 일반에서 끌 수 있음).
- **사용자에게 질문하기**: 에이전트가 무엇을 만들지 불분명하면 작업 전에 선택지 질문(1~3개, 직접 입력 가능)을 띄우고 답을 받은 뒤 진행합니다 (`ask_user` 도구, 설정 → 에이전트에서 끌 수 있음). 터미널에서도 같습니다.
- **설정** (`Ctrl+,`): 일반 / 연결 / 모델 / 출력 형식 / 에이전트 / 함수 호출 / 데이터 / 정보.

### 기능

| 구분 | 내용 |
|---|---|
| 채팅 | 스트리밍, 추론 과정 표시, 중지(Esc), 다시 생성, 메시지 수정 후 재전송, 텍스트 파일 첨부 |
| 접힌 보기 | 추론과 도구 실행은 접힌 채로 진행하고 눌러서 펼칩니다. 같은 종류의 도구 단계가 이어지면 "명령 실행 3개"처럼 한 묶음이 되고, 누르면 목록이 아래로 펼쳐집니다. 승인이 필요한 단계는 자동으로 펼쳐집니다. 경과 시간은 시·분·초로 표시 (설정 → 일반에서 항상 펼치기 가능) |
| 에이전트 | 작업 폴더 안에서 파일 목록·읽기·검색·작성·수정, 셸 명령, 웹 가져오기, 계획 표시. 승인 방식 3단계(읽기 전용 / 승인 후 실행 / 전체 자동) |
| 변경 사항 | 에이전트가 파일을 바꿀 때마다 버전(v0 원본, v1, v2 …)을 남깁니다. 원본과 현재의 차이, 단계별 차이를 보고 파일별·전체 되돌리기, 특정 버전으로 복원 |
| 미리보기 | 파일을 만들거나 고치면 자동으로 띄웁니다. HTML(옆의 CSS·JS·이미지 포함 실행), 이미지·SVG, Markdown, CSV 표, 오디오·비디오, 그 밖의 텍스트는 하이라이트된 소스. 도구 카드와 변경 목록의 눈 아이콘, 파일 탭에서도 열 수 있습니다 |
| 프로젝트 | 이름·설명 + 작업 폴더 + 지침 + 메모리 + 참고 링크를 묶어 관리. 왼쪽 목록에서 프로젝트 이름을 누르면 **프로젝트 홈**이 열립니다(Claude Cowork 의 프로젝트 화면 구성): 가운데에 이름·입력창·그 프로젝트의 작업 목록, 오른쪽에 지침 / 컨텍스트(폴더와 파일, 링크) / 메모리 카드. 홈의 입력창에 적으면 바로 그 프로젝트의 새 작업이 시작되고, 지침·메모리·링크는 system 메시지로 들어갑니다. 대화 중 `/remember 내용` 으로 메모리에 추가, 상단의 프로젝트 이름으로 홈 복귀, 대화를 프로젝트로 옮기기 가능. 컨텍스트 카드에는 프로젝트 폴더가 없어도 에이전트에 연결해 둔 작업 폴더와 그 프로젝트의 작업들이 쓴 폴더가 보이고, 폴더가 없는 프로젝트에서 첫 작업을 시작하면 그 폴더가 프로젝트 폴더가 됩니다. 예약 작업은 없습니다 |
| 추론·샘플링 | `reasoning_effort`(채팅과 에이전트 따로), `preserve_thinking`, `temperature`, `top_p`, `top_k`, `presence_penalty`, `max_tokens`, 스트리밍 on/off |
| 구조화 출력 | `response_format` — json_object / json_schema (스키마 편집) |
| 함수 호출 테스트 | 직접 정의한 함수를 `tools` 로 넘기고, 모델이 호출하면 결과를 손으로 입력해 돌려주기 |
| Tabular | `/v1/tabular/classification`, `/v1/tabular/regression` — CSV 업로드, 결과 표, CSV 저장, 샘플 데이터 |
| 진단 | API 로그(요청 본문, 응답 요약, 원시 응답, curl 복사), 토큰·첫 토큰 시간·tok/s, 요청 한도 잔여량, 컨텍스트 사용량 |
| 기타 | 수식(KaTeX)·코드 하이라이트·표 렌더링, 답변 속 HTML·SVG 코드 미리보기, 대화 검색·이름 변경·내보내기(Markdown/JSON), 라이트/다크 테마, 슬래시 명령 |

## EXAONE Code (터미널)

`claude` 처럼 `exaone` 명령으로 실행합니다. 입력한 글은 회색 바탕 줄(`❯ 내용`)로 또렷하게 남고, `/` 명령 · `@` 파일 목록은 입력 줄 **위쪽**에 뜹니다. `/resume` (또는 `exaone --resume`) 목록에는 이 폴더의 터미널 세션과 함께 데스크톱 앱에서 같은 폴더로 한 에이전트 작업도 나오며, 앱의 작업을 고르면 복사본으로 이어 갑니다. 요청 한도에 걸려 다시 시도할 때는 남은 초가 줄어드는 것이 보입니다. 화면 구성도 Claude Code 를 따랐습니다: 시작하면 터미널을 비우고 맨 위에 EXAONE Code 이름·버전 / 모델·추론 강도 / 작업 폴더 세 줄, 맨 아래에 가로줄 두 개 사이의 `>` 입력 줄, 그 위 오른쪽에 `● medium · /effort`, 그 아래에 권한 모드 줄. 대화는 위에서부터 쌓이고 입력 줄은 항상 터미널 맨 아래에 붙어 있습니다.

**긴 대화 자동 압축** (데스크톱·터미널 공통): Claude Code 의 자동 압축과 같은 식을 EXAONE 의 컨텍스트 창에 적용했습니다. 요청을 보내기 전마다(에이전트의 단계 사이에서도) 사용량을 보고, `524,288 − 20,000(요약 출력용) − 13,000(여유) = 491,288` 토큰을 넘으면 이전 대화를 9개 항목(요청과 의도 / 기술 개념 / 파일과 코드 / 오류와 해결 / 문제 해결 / 사용자 메시지 전체 / 남은 작업 / 현재 작업 / 다음 단계)으로 요약해 바꿔 넣고 이어 갑니다. 사용량은 마지막 응답의 실제 토큰 수에 그 뒤에 붙은 메시지의 어림값(글자 수 ÷ 2)을 더해 셉니다. 세 번 연달아 실패하면 자동 압축을 멈춥니다. 직접 실행은 `/compact`, 끄기는 데스크톱 설정 → 일반, 터미널 `/config`.

### 설치 — `exaone` 명령 등록

`install-cli.bat` 을 한 번 실행하면(`npm link`) 어느 폴더에서나 `exaone` 을 쓸 수 있습니다. 새 터미널을 열어야 적용됩니다.
등록하지 않고 쓰려면 `D:\exaone\exaone-desktop\exaone.cmd` 를 직접 실행하면 됩니다. 추가 패키지는 필요 없습니다.

### 실행

```
exaone                        현재 폴더에서 대화형으로 시작
exaone "할 일"                첫 지시를 주고 시작
exaone -p "할 일"             한 번 실행하고 답만 출력
exaone -c                     이 폴더의 가장 최근 세션 이어서
exaone -r [세션ID]            세션을 골라 이어서
type 로그.txt | exaone -p "요약해줘"
exaone doctor                 설치·연결 상태 점검
```

| 옵션 | 뜻 |
|---|---|
| `--effort low\|medium\|high\|max` | 추론 강도 (기본 medium) |
| `--permission-mode default\|acceptEdits\|plan\|bypassPermissions` | 시작할 때의 권한 모드 |
| `--dangerously-skip-permissions` | 모든 권한 확인을 건너뜀 |
| `--allowedTools "Bash(git:*) Edit"` | 확인 없이 허용할 도구 규칙 |
| `--disallowedTools "Bash WebFetch"` | 모델에게 주지 않을 도구 |
| `--output-format text\|json\|stream-json` | `-p` 출력 형식 |
| `--max-turns`, `--system-prompt`, `--append-system-prompt` | 최대 반복 수, 시스템 프롬프트 교체·추가 |
| `--model`, `--base-url`, `-C <폴더>`, `--verbose` | 모델 ID, API 주소, 작업 폴더, 펼쳐서 보기 |

### 대화형 화면

| 입력 | 동작 |
|---|---|
| `/` | 명령 (자동완성 목록) |
| `@` | 파일 경로 자동완성 — 보낼 때 파일 내용을 함께 첨부 |
| `!명령` | 셸 명령을 바로 실행하고 결과를 대화에 남김 |
| `#메모` | 메모리 파일(EXAONE.md)에 추가 |
| `\`+Enter, Alt+Enter | 줄바꿈 |
| ↑ ↓ | 이전 입력 |
| Shift+Tab | 권한 모드 전환: 기본 → 편집 자동 허용 → 계획 모드 |
| Esc | 실행 중단 (입력 중에는 두 번 눌러 지우기) |
| Ctrl+O | 자세히 보기 — 접혀 있던 추론 내용과 도구 출력을 펼침 |
| Ctrl+C | 입력 지우기, 한 번 더 누르면 종료 |

- **접힌 보기가 기본**입니다. 추론은 "∴ 12초 동안 생각함" 한 줄로, 도구는 요약 한 줄로 보이고, 같은 종류의 도구가 이어지면 "Bash 3회"처럼 한 묶음이 됩니다. Ctrl+O 로 펼칩니다.
- 실행 중에도 입력할 수 있고, 보낸 내용은 지금 작업이 끝난 뒤 이어서 처리됩니다.
- 파일 변경·명령·웹 요청은 확인 상자가 뜹니다: 예 / 예, 다시 묻지 않기 / 아니오(하고 싶은 말 전달). "다시 묻지 않기"는 `.exaone/settings.local.json` 에 규칙으로 저장됩니다.
- **계획 모드**에서는 읽기만 하고 계획을 보여 준 뒤 승인을 받습니다.

명령: `/help` `/clear` `/compact` `/config` `/context` `/cost` `/diff` `/doctor` `/effort` `/export` `/init` `/login` `/logout` `/memory` `/model` `/permissions` `/plan` `/resume` `/rewind` `/status` `/todos` `/verbose` `/exit`

인자를 받는 명령은 목록과 입력 줄에 예시가 같이 보입니다 — `/eff` 까지 치면 목록에 `/effort [low|medium|high|max]`, 고르고 나면 커서 뒤에 흐린 글씨로 `[low|medium|high|max]`. 데스크톱 앱의 `/` 목록도 같습니다.

### 파일

| 종류 | 위치 |
|---|---|
| 토큰(API 키) | 데스크톱 앱 또는 `/login` 으로 등록한 것만 (`~/.exaone/key.txt`, 앱과 함께 사용) |
| 메모리 | `EXAONE.md` (프로젝트), `EXAONE.local.md`, `~/.exaone/EXAONE.md` (사용자) — `/init` 으로 초안 작성 |
| 설정 | `~/.exaone/settings.json`, `.exaone/settings.json`, `.exaone/settings.local.json` (`permissions.allow` / `deny`, `effort`, `model`) |
| 사용자 명령 | `.exaone/commands/이름.md` → `/이름` (`$ARGUMENTS` 치환, 머리말의 `argument-hint:` 는 명령 옆 인자 예시로 표시) |
| 세션 기록 | `~/.exaone/projects/<폴더>/` — `-c`, `-r`, `/resume` 로 이어서 |

Claude Code 에 있지만 넣지 않은 것: MCP 서버 연결, 훅, 하위 에이전트, 이미지 입력(모델이 텍스트 전용), IDE 연동.

## 알아 둘 점

- **요청 한도**: 계정 한도가 초당 1회라 요청 사이를 1.1초 띄웁니다.
- **자동 다시 시도**: 네트워크 문제(연결 실패, 응답을 받는 도중 끊김)나 408·409·429·5xx 응답이면 Claude Code 와 같은 방식으로 다시 보냅니다 — 최대 10번, 0.5초에서 시작해 두 배씩(최대 32초) 간격을 늘리고, 서버가 `retry-after` 를 주면 그 시간을 따릅니다(60초를 넘으면 기다리지 않고 오류). 기다리는 동안 "API 오류 (연결 오류) · 4초 후 다시 시도… (시도 2/10)" 가 남은 시간과 함께 보이고, 중지(Esc)하면 바로 멈춥니다. 받다 만 답은 버리고 처음부터 다시 받습니다. 400·401 처럼 다시 보내도 소용없는 오류와, 완료 신호 없이 끝난 스트림(시간 제한)은 다시 시도하지 않습니다. 횟수는 터미널에서 `EXAONE_MAX_RETRIES`, 앱에서는 설정 파일의 `maxRetries` 로 바꿉니다(0 이면 끔). `exaone -p --output-format stream-json` 에서는 `system`/`api_retry` 이벤트로 알립니다.
- **실시간 연동**: 앱의 Code 탭과 터미널이 같은 세션을 열어 두면, 한쪽에서 입력한 지시와 진행 중인 작업(생각, 답변 글자, 도구 실행)이 다른 쪽에 그대로 실시간으로 보입니다. 작업하는 쪽이 세션 파일 옆의 `<세션 id>.live` 에 일어나는 일을 적고 다른 쪽이 0.1초 간격으로 읽는 방식입니다. 한쪽이 작업 중일 때 다른 쪽에서는 보낼 수 없고(터미널은 대기열에 넣음), 중지(Esc / 중지 버튼)는 어느 쪽에서든 됩니다. `exaone -p` 로 돌린 작업도 앱에 실시간으로 보입니다.
- **로고**: 앱 폴더의 `assets/logo.(svg|png|jpg|webp)` 또는 `~/.exaone/logo.*` 에 그림 파일을 두면 사이드바와 시작 화면의 "E" 표시 자리에 쓰입니다(png·jpg 는 창 아이콘에도). 파일이 없으면 Desktop은 차콜 E, Code는 공식 EXAONE 워드마크와 Code 이름을 표시합니다. 공식 EXAONE 워드마크는 라이트·다크 테마에 맞춰 표시되며, 기본 창 아이콘도 포함됩니다. 출처와 디자인 기준은 `assets/README.md`, `DESIGN.md`에 기록했습니다.
- **추론 강도 기본값**: 채팅 `high`, 에이전트 `medium`(공식 에이전트 가이드의 예시 값). API 기본값은 `max` 입니다.
- **응답이 끊기는 경우**: 스트림이 완료 신호(`finish_reason`) 없이 끝나면 조용히 넘어가지 않고 오류로 표시합니다. 추론 강도를 낮춰 다시 시도해 보세요.
- **API 로그 파일**: 요청·응답 원문을 `logs/` 폴더에 JSON 으로 남깁니다(최근 40개, 설정 → 데이터에서 끌 수 있음). 프롬프트와 파일 내용이 들어가니 공유할 때 주의하세요.
- **에이전트의 명령 실행은 격리되지 않습니다.** 작업 폴더에서 실제로 실행되므로 "승인 후 실행"(기본값)을 권합니다. 파일 도구는 작업 폴더 밖 경로를 거부합니다.
- **변경 사항 기록**은 에이전트의 파일 도구(write_file · edit_file)로 바꾼 내용만 추적합니다. 명령 실행으로 바뀐 파일은 다음에 그 파일을 고칠 때 "도구 밖 변경"으로 잡힙니다.
- **HTML 미리보기**는 작업 폴더 전용 출처에서 스크립트를 실행합니다. 앱 화면이나 다른 폴더에는 접근할 수 없지만 네트워크 요청은 막지 않습니다.
- 대화 제목은 요청 수를 아끼려고 모델을 부르지 않고 첫 메시지에서 잘라 만듭니다.

## 문제가 생기면

400 / 422 가 나오면 **API 로그**에서 요청 본문을 확인하고 아래를 하나씩 바꿔 보세요. 도구 호출·구조화 출력은 공식 문서에 요청 예시가 없어 OpenAI 형식으로 보냅니다.

| 증상 | 조치 |
|---|---|
| 응답이 몇 분 뒤 끊김 / 추론만 하고 끝남 | 추론 강도를 낮추기. `logs/` 의 해당 JSON 끝부분(`raw`)과 `stream` 항목 확인 |
| 에이전트 모드에서 바로 400 | 설정 → 에이전트의 추론 강도를 `medium` 대신 `low` 나 `high` 로 (모델 문서에는 low/high/max 만 적혀 있음) |
| 여러 턴 대화에서만 오류 | 설정 → 모델 → **추론 내용 재전송** 끄기 |
| 구조화 출력 오류 | 설정 → 출력 형식에서 `strict` 끄기, 또는 json_object 로 |
| 401 | 설정 → 연결에서 키와 출처 확인 |
| 429 | 자동으로 다시 시도합니다. 계속되면 사이드바의 잔여 한도 확인, 설정 → 연결에서 요청 간격 늘리기 |
| "API 오류 (연결 오류) · … 다시 시도" 가 계속됨 | 네트워크·프록시·방화벽 확인. 10번 실패하면 오류로 끝나며 "다시 생성"으로 이어서 할 수 있습니다 |

## 구조

```
main.js              Electron 메인: 창, IPC, 키 관리, 미리보기용 파일 스킴, 로그 저장
preload.js           화면에 노출하는 API (contextBridge)
src/exaone.js        API 클라이언트 (SSE 파싱, 스트림 진단, Tabular multipart)
src/tools.js         에이전트 도구 구현
src/history.js       파일 버전 기록 (대화별 내용 주소 저장소)
src/store.js         설정·대화 저장
src/sessions.js      터미널 세션 ↔ 앱 대화 변환, Code 탭의 세션 읽기·쓰기
src/live.js          실시간 연동 (작업 중인 내용을 <세션>.live 로 주고받기)
renderer/js/retry.js 실패한 요청을 다시 보내는 규칙 (앱 · 터미널 공용)
cli/                 터미널 에이전트 (exaone-code.js 진입점, tui.js 화면, agent.js 루프·권한, markdown.js, term.js, store.js)
renderer/            화면 (프레임워크 없이 HTML/CSS/JS)
renderer/vendor/     marked, DOMPurify, highlight.js, KaTeX (오프라인 동작용 사본)
```

대화·설정·파일 버전 기록은 `%APPDATA%\EXAONE Desktop` 에 저장됩니다(설정 → 데이터).
