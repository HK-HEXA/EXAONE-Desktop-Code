# EXAONE Desktop / Code

The visual reference is the EXAONE official Showroom at https://showroom.exaone.ai/en, inspected on 2026-11-11. These are task-focused local clients; the site's branding is adapted to the existing chat, tools, projects, settings and terminal flows.

Use the original EXAONE wordmark geometry with a separate Desktop or Code descriptor. Desktop uses a charcoal E tile; Code uses the official EXAONE wordmark with a separate Code descriptor, with a small lavender terminal-window symbol drawn in continuous strokes. Its terminal banner displays EXAONE in bold and Code in lavender; model and folder information follow on separate lines inside a thin lavender terminal frame. Preserve user logo overrides.

Light surfaces: #fafafa, #f4f4f5 and white. Text: #131415, #4e5055, #66666f. Borders: #dfe0e1, #afb1b5. Main actions are charcoal; selections use #ededff. Dark surfaces: #111113, #0a0a0a, #1d1e20. Dark text: #f4f4f5, #afb1b5, #95979d. Dark actions use #c5c6ff. Lavender focus: #6567c7 in light mode and #b8baff in dark mode. Status colors remain semantic.

Use the existing Pretendard/system Korean sans stack and monospace stack for code. App controls keep compact 6–12 px corners; composer 16 px. Brand assets are local for offline startup. Keyboard focus must stay visible and reduced-motion preferences must be honored. Native title-bar colors match the renderer tokens. Terminal brand color approximates lavender with ANSI 256 index 147 and respects NO_COLOR.
